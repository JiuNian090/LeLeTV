# 代码规范规则

> 按需加载 — 修改源代码、写提交信息时读取。

---

## 提交规范

**格式：** `<type>: <简短描述>`

```
<type>: <简短描述（中文，≤50 字）>

<详细描述（可选，中文）>
```

| 类型 | 用途 |
|------|------|
| `feat:` | 新功能 |
| `fix:` | Bug 修复 |
| `docs:` | 文档更新 |
| `refactor:` | 代码重构（不修 bug 不加功能） |
| `style:` | 样式 / UI 调整 |
| `perf:` | 性能优化 |
| `test:` | 测试相关 |
| `chore:` | 构建 / CI / 配置 |

要求：

- 简短描述用中文，不超过 50 字，描述**做了什么**而非**为什么做**
- 不添加尾部句号

## 编码规范

### LeLeTV 前端特有

- 所有用户搜索输入需 `trim()` + `encodeURIComponent()`
- 视频 / 图片 URL 请求必须处理跨域和 404 场景
- 播放器状态变更通过事件发布，不直接操作 DOM
- 列表渲染使用 `DocumentFragment` 批量追加，减少回流
- 深色主题优先，确保所有 UI 组件都有 dark 样式变体
- `js/` 下的模块是**拼接式打包**（非 ESM import），新增文件必须登记进 `scripts/build-bundles.mjs` 的 `CORE` / `APP` / `PLAYER` 清单并注意顺序依赖

### 通用

- 使用 ES6+ 语法：`async/await`、解构赋值、可选链、空值合并
- 用户输入必须校验（trim + sanitize + encode）
- 不硬编码密钥，通过环境变量注入
- 不输出未验证的 HTML / URL / 脚本（XSS 防护）
- 保持既有缩进与命名风格，函数单一职责
- 项目未配置 ESLint / Prettier，不要凭空引入新工具链

### 错误处理等级

| 层级 | 场景 | 处理方式 |
|------|------|---------|
| 用户可见 | 搜索无结果、播放失败 | 显示友好提示 + 重试按钮 |
| 控制台日志 | API 解析异常、缓存未命中 | `console.warn()` + 上下文 |
| 静默容错 | 次要字段缺失、封面图 404 | 使用默认值，不中断流程 |
